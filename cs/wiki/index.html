Instalace

NanoRDS je softwarový RDS kodér pro Linux a Windows. Generuje RDS subnosnou na 57 kHz a samostatný stereofonní pilot na 19 kHz. Zvukový výstup má vzorkovací frekvenci 192 kHz. Na obou systémech se používá stejný GNU Makefile.

Stažení

Hotové verze si můžete stáhnout z GitHub Releases nebo si naklonovat zdrojový kód:

git clone https://github.com/barteqcz/NanoRDS

Při kompilaci ze zdrojového kódu nejprve nainstalujte vývojové knihovny pro svůj systém. Knihovny třetích stran nejsou součástí zdrojového kódu.

Linux (Debian / Ubuntu)

sudo apt update && sudo apt install build-essential pkg-config libsamplerate0-dev libao-dev
make
./build/linux/nanords --help

Další linuxové distribuce: nainstalujte GNU Make, GCC, pkg-config, libao a libsamplerate včetně vývojových hlavičkových souborů a spusťte make.

Windows (MSYS2 UCRT64)

Nainstalujte MSYS2 a otevřete terminál UCRT64 (nikoli běžný terminál MSYS). Nainstalujte potřebné balíčky:

pacman -S --needed make mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-pkgconf mingw-w64-ucrt-x86_64-libsamplerate mingw-w64-ucrt-x86_64-portaudio
make
./build/windows/nanords.exe --help

Při spouštění lokálně zkompilovaného programu mimo MSYS2 musí Windows najít potřebné DLL knihovny (například libsamplerate-0.dll a libportaudio.dll). Zkopírujte požadované DLL vedle nanords.exe, případně přidejte příslušnou složku MSYS2 do proměnné PATH. Archivy pro Windows v GitHub Releases závislosti obsahují.

Zvukový výstup a volby kompilace

NanoRDS automaticky používá výchozí výstupní zvukové zařízení v obou systémech. Ve Windows používá PortAudio WASAPI ve sdíleném režimu, takže mohou současně přehrávat zvuk i další aplikace. Přepínače --device ani --list-devices nejsou k dispozici.

Ve Windows nastavte výchozímu přehrávacímu zařízení frekvenci 192000 Hz v nabídce Zvuk → Přehrávání → Vlastnosti → Upřesnit (dialog lze otevřít příkazem mmsys.cpl). Při nekompatibilní frekvenci směšovače se NanoRDS nespustí, aby nedocházelo ke ztrátě RDS subnosné 57 kHz. Systémové zvuky a zvuková vylepšení mohou signál pro vysílač narušovat.

FM multiplex je na levém zvukovém kanálu, pravý kanál je tichý. Program nepřijímá hudební ani jiný zvukový vstup. Zvukové zařízení i celý výstupní řetězec musí zachovat signál se vzorkovací frekvencí 192 kHz.

Makefile podporuje následující příkazy:

make # kompilace
make clean # smazání vygenerovaných souborů
make clean && make RBDS=1 # kompilace s podporou RBDS

Frekvence RDS je pevně nastavena na 57 kHz ve zdrojovém kódu. Nelze ji změnit přepínačem ani parametrem Makefile. Aktuální Makefile nepodporuje make install, make uninstall ani make package.

Argumenty příkazové řádky

Seznam dostupných přepínačů zobrazíte pomocí nanords --help (ve Windows nanords.exe --help). Nápověda se vypíše také při chybných přepínačích nebo hodnotách.

nanords --pi 1234 --ps SAMPLE --rt "Ukazkovy RadioText" --pty 10 nanords --af a 87.7 98.0 88.6 nanords --af b 87.7 97.2 94.4 regional 105.2 94.1 nanords --file commands.txt

Běžné přepínače: --pi HEX, --ps TEXT, --rt TEXT, --pty N, --ptyn TEXT, --ms 0|1, --tp 0|1, --di N, --ecc HEX, --lic HEX, --stereo N, --rds N, --af a ..., --af b ... a --file PATH. Další nastavení, například TA, RT+ a CT, lze měnit pomocí příkazů v souboru.

Metoda AF musí být uvedena výslovně: --af a pro metodu A a --af b pro metodu B. Staré přepínače --af-method, --af-tuned, --af-regional, --fifo a --device už nejsou podporovány.

Ovládání textovým souborem

Na Linuxu i Windows načítá přepínač --file běžný existující textový soubor. Není potřeba FIFO ani příkaz mkfifo. NanoRDS načte obsah při spuštění a přibližně každých 250 ms kontroluje uložené změny.

Vytvořte soubor commands.txt a spusťte NanoRDS:

./build/linux/nanords --file commands.txt

Ve Windows:

./build/windows/nanords.exe --file commands.txt

Za běhu programu soubor upravte a uložte. Každý příkaz musí být na samostatném řádku. Podporován je text UTF-8 a konce řádků LF i CRLF. Soubor musí existovat při spuštění a může mít nejvýše 64 KiB.

Důležité: smazání řádku z textového souboru nevrací dříve nastavenou hodnotu. Použijte nový příkaz, AF c pro vymazání AF nebo RESET pro obnovení výchozích nastavení. Každý nový příkaz AF a či AF b nahrazuje předchozí seznam AF.

Příkazy v textovém souboru

Identifikace stanice a RadioText

PS — název stanice (Programme Service), maximálně 8 znaků.

PS SAMPLE

RT — RadioText, maximálně 64 znaků.

RT Ukazkova zprava RadioText

PI — 16bitový hexadecimální identifikační kód stanice. V sestavení RBDS mohou být přijímány také odpovídající severoamerické volací značky.

PI 1234

PTY — typ programu (0–31); viz PTY kódy níže. PTYN — rozšířený název typu programu, maximálně 8 znaků (pro vymazání použijte PTYN -).

PTY 10
PTYN POP

Alternativní frekvence (AF)

Metoda A vysílá jednoduchý seznam alternativních frekvencí bez dvojic. Na obou rozhraních použijte písmeno a:

AF a 87.7 98.0 88.6

Odpovídající přepínač CLI:

nanords --af a 87.7 98.0 88.6

Metoda B vysílá dvojice frekvencí vztažené ke konkrétnímu vysílači. První frekvence je frekvence vlastního vysílače, za ní následují alternativy se stejným programem. Před regionálními variantami uveďte regional:

AF b 87.7 97.2 94.4 regional 105.2 94.1

Odpovídající přepínač CLI:

nanords --af b 87.7 97.2 94.4 regional 105.2 94.1

V příkladu vzniknou dvojice se stejným programem 87.7 → 97.2 a 87.7 → 94.4 a regionální dvojice 105.2 → 87.7 a 94.1 → 87.7. Pořadí ve dvojicích určuje kodér automaticky. Frekvence se zadávají jako čísla (např. 105.7), bez přípony „MHz“.

Metoda B podporuje jeden seznam pro daný vysílač s nejvýše 12 alternativami. Frekvence musí být v pásmu 87.6–107.9 s krokem 0.1 a nesmějí se opakovat. Pokud použijete regional, musí po něm následovat alespoň jedna frekvence.

Vymazání celého seznamu AF:

AF c

Platné podoby příkazu jsou pouze AF a, AF b a AF c. Starý příkaz AF s byl odstraněn.

RT+ a další příznaky

RTPF nastavuje příznaky RT+: 0 = žádný, 1 = toggle, 2 = running, 3 = oba.

RTPF 2

RTP určuje dvě značky RT+ pro aktuální RadioText. Formát: typ1,začátek1,délka1,typ2,začátek2,délka2 (RT+ se vysílá ve skupině RDS 11A).

RTP 4,0,6,1,9,8

MS označuje hudbu (1) nebo mluvené slovo (0). TP označuje stanici s dopravním zpravodajstvím, TA právě probíhající dopravní hlášení a DI informace pro dekodér (0–15).

MS 1 TP 0 TA 0 DI 1

ECC je rozšířený kód země (hexadecimální), LIC kód jazyka (hexadecimální). CT povoluje (1) nebo vypíná (0) vysílání času (Clock Time).

ECC E2 LIC 06 CT 1

STEREO ovládá úroveň stereofonního pilotu 19 kHz a RDS úroveň subnosné 57 kHz (rozsah 0–100, lze použít desetinná čísla). Nula příslušný signál vypne.

STEREO 9 RDS 4.5

Pro správnou úroveň signálu se vyvarujte nechtěného zeslabení či dalšího zpracování zvuku ve výstupním řetězci.

RESET obnoví výchozí nastavení kodéru a nepřijímá žádný parametr.

RESET
