Instalace

Závislosti

NanoRDS závisí na několika balíčkách.

Distribuce založené na Debianu:

sudo apt install libao-dev libsamplerate0-dev

Distribuce založené na Arch Linuxu:

sudo pacman -S libao libsamplerate

Distribuce založené na Fedoře:

sudo dnf install libao-devel libsamplerate-devel

Stahování

Kóder si můžete stáhnout buď skrze tlačítko na hlavní strance, nebo s použitím git:

git clone https://github.com/barteqcz/NanoRDS

Kompilace

Soubor Makefile nabízí několik možností:

  • make - kompiluje program.
  • make install - kompiluje program a instaluje ho celosystémově, díky čemu spuštění příkazu nanords kdekoliv v systému spouští kóder.
  • make uninstall - odinstaluje program celosystémově, takže spuštění příkazu nanords kdekoliv v systému už nebude kóder spouštět.
  • make clean - odstraňuje všechny .o soubory a spustitelný soubor ze složky NanoRDS.

Pro spuštění kóderu, nainstalovaného celosystémově, spusťte níže uvedený příkaz:

nanords


Pro spuštění kóderu, který nebyl nainstalován celosystémově, spusťte tento příkaz ve složce NanoRDS:

./nanords

Pozor: oba make install a make uninstall musí být spuštěné jako root (např. sudo make install nebo sudo make uninstall)

CLI funkce

Pro seznam všech dostupných CLI příkazů proveďte tento příkaz:

nanords --help

Vytváření FIFO

Vytvořte FIFO:

mkfifo rdsfifo

Spusťte NanoRDS s příslušnou CLI opcí:

nanords --fifo rdsfifo

Teď můžete odesílat příkazy k FIFO pro ovládání RDS (manuálně, nebo s použitím nějakého zautomatizovaného skriptu). Každý řádek musí začínat správným příkazem, následovaným jedním mezerníkem a požadovanou hodnotou. Jakýkoliv jiný formát řádku je ignorován bez žádné informace.

Pozor: Pokud vytvoříte FIFO ve složce jiné než té, ve které je lokalizován spustitelný soubor NanoRDS, pamatujte, abyste v příkazu použili plnou cestu k souboru.

FIFO příkazy

PS - znamená Program Service a umožňuje vysílat 'název' stanice, který je zobrazován na každém přijímači podporujícím RDS (je to zakladní funkčnost). Maximální délka PS je 8 znaků. Takto můžete PS vysílat skrz FIFO

PS * RDS *


RT - znamená RadioText a je v podstatě delší zprávou, která je zobrazována ve většině přijímačů podporujících RDS. Může obsahovat maximálně 64 znaků a takto ji můžete vysílat skrz FIFO

RT Toto je zpráva RadioText :)


RTPF - 2-bitové čislo, použivané když chcete vysílat RT+. Nastavuje RT+ příznaky - 'running' a 'toggle'

  • RTPF 0 - deaktivuje oba příznaky,
  • RTPF 1 - nastaví 'toggle' příznak,
  • RTPF 2 - nastaví 'running' příznak,
  • RTPF 3 - nastaví oba příznaky,

Příklad použití:

RTPF 2


RTP - dodavá data pro skupiny RT+ (v NanoRDS, RT+ je vysílán ve skupině 11A). Format příkazu:

typ obsahu 1, start 1, délka 1, typ obsahu 2, start 2, délka 2

Bere data z RT. Příklad použití:

RTP 4,0,6,1,9,8


PTY - definuje Program Type, v podstatě to, jaký obsah vysílá vaše stanice. V NanoRDS je PTY nastavované pomocí příkazu s příslušným kódem

PTY 10

Pozor: seznam všech kódů PTY najdete tady



PTYN - v podstatě rozšíření PTY. Schopné obsahovat maximálně 8 znaků, obvykle používané pro přidání nějakých dodatečných informací o obsahu vysílání stanice.

PTYN CHR


PI - Program Identification je unikátní 16-bitový hexadecimalní 4-znakový kód, ktérý identifikuje stanicí. Takto ho můžete nastavit v NanoRDS skrz FIFO

PI 2F08


AF - AF znamená Alternative Frequencies a umožňuje přijímači přepinat frekvence když signál slabne, mezi těmi, které naznačite. AF má dvě metody - NanoRDS využivá metodu A,která se obvykle používá - je pohodlnější a jednodušší

Takto můžete používat AF v NanoRDS. Existuje doporučení, aby první frekvence na seznamu byla frekvencí aktuálně nastavovaného vysílače.

AF s 105.1 87.7 96.4

Jestli chcete vymazat AF seznam, použijte

AF c


ECC - 8-bitový hexadecimální kód, který definuje zemi původu stanice. Může být stejný pro mnoho zemí, protože druhá podmínka pro identifikaci zemí je PI kód. Pokud chcete tuto funkci vypnout, nastavte její hodnotu na 0.

ECC E2


LIC - 8-bitový hexadecimální kód, který definuje jazyk stanice. Pokud chcete tuto funkci vypnout, nastavte její hodnotu na 0.

LIC 06


MS - music/speech příznak. Hudba je 1 a řeč je 0.

MS 1


TP - Traffic Program příznak. Definuje, zda stanice vysílá dopravní informace. Pokud ano, je nastaveno na 1; pokud ne, je nastaveno na 0.

TP 1


TA - Traffic Announcement příznak - signalizuje, že dopravní informace jsou vysílány právě v této chvíli.

TA 1


DI - Decoder Information - umožňuje signalizování podrobností kóderu dekóderovi, což usnadňuje dekódování signálu RDS. Dodatečně určuje, zda stanice vysílá statické, nebo dynamické PTY.

DI 1


STEREO - umožňuje ovládání hlasitosti subnosné Stereo

STEREO 9

Pokud chcete vypnout subnosnou Stereo, jednoduše nastavte její hodnotu na 0.


RDS - umožňuje ovládání hlasitosti subnosné RDS

RDS 4.5

Pokud chcete vypnout subnosnou RDS, jednoduše nastavte její hodnotu na 0.

Pozor: úrovně RDS a stereo subnosných budou přesné pouze v případě, že je výstupní hlasitost vašeho systému nastavena na 0dB.


RESET - nevyžaduje žádné dodatečné opce - resetuje všechna nastavení kóderu do výchozích.

RESET
